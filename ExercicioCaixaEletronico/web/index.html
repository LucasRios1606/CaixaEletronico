COMO FUNCIONA

Seu laboratório de caixa

Saque e depósito: alteram apenas o saldo demonstrativo. Valores negativos, zerados e saques sem saldo são recusados.

Terminal + navegador: no modo ambos, as duas interfaces compartilham a mesma conta. A página se atualiza automaticamente.

Dados salvos: fechar a página ou encerrar o programa não apaga a conta. Uma conta nova começa com R$ 50.000,00 fictícios. O histórico continua nas próximas execuções.

Não há autenticação nem conexão com instituições financeiras. Use somente como projeto de estudo local.
